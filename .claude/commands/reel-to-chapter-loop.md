Run the Reel → Chapter loop.

1. **instagram-shorts-strategist** — hooks, scripts, caption, CTA, UTM campaign name.
2. **chapter-editor** — confirm the destination chapter can carry the traffic. If it is still thin, say so and expand it first.
3. **analytics-tracking-agent** — verify the UTM link fires `reel_source_visit` and `chapter_view`, and that the campaign name is consistent with what is already published.
4. **seo-research-strategist** — confirm the chapter's FAQ answers what this Reel's viewers will type next.

Rules:
- Every Reel links to a **chapter**, never the homepage.
- An untagged link is an untracked link.
- Drafts only. Never publish.

Return: Reel pack · exact UTM URL · destination chapter · 24h/72h/7d metrics to watch.
