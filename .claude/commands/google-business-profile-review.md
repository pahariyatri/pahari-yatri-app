Run the Google Business Profile review.

1. **google-business-profile-strategist** — eligibility check first. Then audit name, category, description, address visibility, service area, phone/WhatsApp, website link, photos, posts, services, Q&A, reviews.
2. **local-verification-editor** — clear any cultural claim (devta, temple, ritual, local belief) appearing in a proposed GBP description or post before it is drafted as fact.
3. **reputation-local-trust-agent** — review response templates, Q&A ideas, and a check that nothing here reads as a fabricated trust signal.
4. **qa-security-reviewer** — only if this run touches any repo file. Skip for a pure external-profile review.

Rules:
- Browser access only if already logged in. Never ask for a password.
- Stop immediately if an OTP, passkey, payment, permission, or billing screen appears.
- Do not change category, name, or address without reporting the impact first — that decision is founder-only.
- Prepare, never publish.

Return:
- eligibility verdict
- current GBP status, field by field (or "no profile exists")
- name / category / address / service-area audit
- suggested description
- suggested services
- suggested posts (drafted, not sent)
- photo checklist
- Q&A ideas
- review response templates
- exactly what needs founder approval before anything goes live
